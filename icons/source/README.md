# 확장 아이콘 원본

`cup-tteokbokki.png`가 모든 배포 아이콘의 기준이다. 보라색 둥근 사각형 안에 흰색 컵떡볶이와 작은 꼬치를 표현한다. 선택한 ImageGen 시안의 형태를 유지한 1254×1254px RGBA 원본이다.

## PNG 생성

저장소 루트에서 실행한다. 프로젝트의 기존 Playwright/Chromium을 사용하며 새 라이브러리나 외부 서비스는 필요하지 않다.

```powershell
npx playwright install chromium
npm run icons:generate
```

Chromium이 이미 설치되어 있다면 첫 명령은 생략한다. 고해상도 원본을 출력 크기의 4배로 먼저 줄인 뒤 최종 크기로 축소하고 투명도를 유지한다. PNG 헤더의 실제 크기도 검사한다. 재생성 후에는 `npm run build`로 확장 출력을 갱신한다.

| 용도                    | 크기                               |
| ----------------------- | ---------------------------------- |
| Chrome 도구 모음        | 16, 24, 32, 48, 64px               |
| 확장 정보·관리 화면     | 16, 24, 32, 48, 64, 96, 128, 192px |
| 팝업 제품 이미지        | 128px PNG를 40 CSS px로 표시       |
| 팝업·설정 페이지 파비콘 | 16, 32px                           |

배포 자산은 `public/icons/`에 두고, 기존 `icons/` 대응 파일도 같은 내용으로 갱신한다. `96.png`와 `192.png`는 기존 경로를 유지한다. WXT의 자동 탐색과 별개로 manifest에 사용할 경로와 크기를 명시한다.

고해상도 원본은 패키지에 포함하지 않는다. Chrome 확장 아이콘은 PNG를 사용하며, 아이콘 교체를 위해 권한이나 웹 접근 가능 자산을 추가하지 않는다. 메뉴·버튼·로더의 기능별 UI 기호는 제품 아이콘과 별개다.

128px 아이콘은 Chrome 웹 스토어 규격에 맞춰 사방 16px 투명 여백을 두고 원본을 가운데 96px 영역에 배치한다. 다른 크기의 도구 모음 아이콘에는 이 여백을 추가하지 않는다.
