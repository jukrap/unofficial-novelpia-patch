# 개인정보 처리 안내

적용 대상: Unofficial Novelpia Patch 0.1.1~0.1.2

최종 수정일: 2026년 11월 1일

이 확장은 노벨피아의 읽기 화면을 조절합니다. 개발자가 운영하는 수집 서버, 광고용 추적 코드나 외부 분석 서비스로 사용 기록을 보내지 않습니다. 다만 Chrome 동기화와 외부 글꼴·이미지 요청은 아래와 같이 발생할 수 있습니다.

## 처리하는 정보와 저장 위치

| 정보                                                                        | 용도                         | 저장 위치                        |
| --------------------------------------------------------------------------- | ---------------------------- | -------------------------------- |
| 읽기 설정, 사용자 프리셋 이름·설명·설정값, 선택한 프리셋                    | 읽기 환경 저장               | 확장의 `chrome.storage.sync`     |
| 이미지 주소, 등록 이미지·사용자 글꼴의 참조 ID                              | 선택한 배경과 글꼴 연결      | 설정·프리셋과 함께 동기화 저장소 |
| 회차 ID, 문단 식별값·글자 위치 또는 90% 이상 도달 여부                      | 자동 이어보기와 수동 북마크  | 확장의 `chrome.storage.local`    |
| 회차 ID 목록, 날짜별 독서 시간, 기록 시작 시각과 중복 합산 방지 정보        | 로컬 독서 통계               | 확장의 `chrome.storage.local`    |
| 최근 선택한 색상                                                            | 색상 선택기의 최근 항목 표시 | 확장의 `chrome.storage.local`    |
| 초기 화면 색상, 저장 실패 복구본·설정 이전용 사본, 원래 뷰어 설정 복원 정보 | 화면 준비와 설정 복구        | 확장의 `chrome.storage.local`    |
| 등록한 이미지 파일·파일명·크기·등록 시각                                    | 파일 배경 표시와 관리        | 확장 영역의 IndexedDB            |
| 등록한 글꼴 파일·파일명·표시 이름·지원 두께 정보                            | 사용자 글꼴 표시와 관리      | 확장 영역의 IndexedDB            |

Chrome 동기화가 켜져 있으면 `chrome.storage.sync`의 정보는 Chrome의 동기화 기능을 통해 다른 기기로 옮겨질 수 있습니다. 개발자가 해당 정보에 접근하는 서버는 없습니다. 등록 파일과 로컬 읽기 기록은 Chrome 동기화에 넣지 않습니다.

스크롤·페이지 선택은 확장 설정과 함께 동기화 저장소에 보관합니다. 실제 전환에는 원사이트 기능과 기존 저장소를 사용하며, 확장이 변경하기 직전의 원사이트 읽기 방식은 확장 로컬 저장소에 보관했다가 기본 뷰어로 돌아갈 때 복원합니다. 전환 중 회차 ID와 본문 위치는 노벨피아 페이지의 `sessionStorage`에 임시로 저장하고 다음 뷰어에서 읽은 뒤 삭제합니다. 정주행 등 나머지 원사이트 옵션은 원사이트의 기존 설정 저장 방식을 사용합니다.

확장은 본문 배치와 위치 복원을 위해 열린 회차의 본문을 메모리에서 읽습니다. 작품 본문·제목·계정 정보·로그인 비밀번호·결제 정보는 확장의 읽기 기록에 저장하지 않습니다. 등록 파일의 이름과 사용자가 작성한 프리셋 이름·설명에는 개인 정보가 들어갈 수 있으므로 직접 관리해 주세요.

## 외부 연결

- **웹글꼴:** 기본 독서 글꼴을 포함해 선택한 웹글꼴과 미리보기를 표시할 때 Google Fonts와 jsDelivr 등 글꼴 제공처에 CSS·글꼴 파일을 요청합니다. IP 주소와 브라우저 요청 정보가 해당 제공처에 전달될 수 있습니다. 실제 글꼴 출처는 [글꼴 고지](../public/licenses/Reading-Font-Sources.txt)에 있습니다.
- **이미지 주소:** 사용자가 지정한 이미지 URL을 브라우저에서 불러옵니다. 해당 서버에는 일반적인 이미지 요청 정보가 전달될 수 있습니다. 요청을 원하지 않으면 단색 배경이나 등록 파일을 사용하세요.
- **Chrome 동기화:** 동기화 저장소의 데이터 처리는 사용자의 Chrome 설정과 Google 정책을 따릅니다.
- **노벨피아 서비스:** 회차 조회·이동·추천은 원사이트의 기능을 사용합니다. 확장은 별도 본문 수집 API를 만들거나 접근 권한을 우회하지 않습니다.
- **문의 링크:** GitHub 링크는 사용자가 눌렀을 때 열립니다. 공개 이슈에 작성한 내용은 공개될 수 있습니다.

등록한 글꼴·이미지 파일은 개발자나 글꼴 제공처에 업로드하지 않습니다. 동봉된 UI 글꼴과 기본 배경 이미지 4종은 외부 다운로드 없이 사용합니다. 기본 배경은 설정에 배경 ID만 저장하며 등록 이미지 보관함을 사용하지 않습니다.

## 독서 통계

통계는 기본적으로 이 브라우저에 기록합니다. 활성 창에서 본문이 보이는 동안의 추정 독서 시간, 서로 다른 회차 수와 독서한 날짜를 집계합니다. 시크릿 창에서는 집계하지 않습니다. 설정창·회차 목록 등이 본문을 가리거나 읽기 조작 없이 5분이 지나면 시간 집계를 중단합니다.

**설정 페이지 → 기타 → 통계 기록**에서 끌 수 있습니다. 기록을 꺼도 기존 숫자는 유지하며, **통계 삭제**로 지울 수 있습니다. 통계는 설정 파일 내보내기·가져오기 대상이 아닙니다.

## 삭제와 보관

확장은 설정·프리셋·파일·위치 기록을 기능에 필요한 동안 보관하며 자동 만료시키지 않습니다.

- **읽기 설정:** 기타의 설정 초기화로 기본값으로 되돌립니다. 프리셋, 등록 파일, 위치·북마크·통계는 삭제하지 않습니다.
- **프리셋:** 프리셋 편집 화면에서 삭제합니다.
- **북마크:** 해당 회차의 하단 탐색 바에서 북마크를 해제합니다.
- **이미지:** 외관의 등록 이미지 관리에서 삭제합니다. 사용 중이라면 먼저 현재 설정과 프리셋에서 다른 배경을 선택해야 합니다.
- **사용자 글꼴:** 사용자 글꼴 화면에서 삭제합니다. 사용 중인 설정·프리셋은 먼저 다른 글꼴로 바꿔야 합니다.
- **독서 통계:** 기타의 통계 삭제로 지웁니다. 기록 스위치 상태는 유지합니다.

자동 저장한 읽기 위치를 한꺼번에 지우는 전용 메뉴는 현재 없습니다. 확장을 제거하면 브라우저가 관리하는 확장 로컬 저장소도 제거됩니다. Chrome 동기화 데이터와 직접 내보낸 JSON 파일은 별도로 관리해야 합니다. 원사이트의 계정·기존 설정은 확장 제거로 삭제되지 않습니다.

설정 파일에는 설정과 프리셋만 들어가며, 등록 파일의 실제 내용과 독서 기록은 포함되지 않습니다. 공유하거나 문의에 첨부하기 전에 이미지 URL, 이름·설명 등의 내용을 확인하세요.

## 권한과 문의

`storage` 권한은 설정·프리셋·독서 기록을 보관하는 데 사용합니다. 콘텐츠 스크립트는 `novelpia.com`과 `www.novelpia.com`의 `/viewer/` 화면에서 읽기 UI를 적용합니다.

이 확장은 처리한 사용자 데이터를 판매하거나 광고·신용 평가에 사용하지 않습니다. Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 따릅니다.

개인정보 관련 문의는 [프로젝트 문의 창구](https://github.com/jukrap/unofficial-novelpia-patch/issues)로 보내 주세요. 공개 이슈에는 민감한 내용을 적지 마세요. 보안 취약점은 [보안 제보 안내](../SECURITY.md)를 따릅니다.
