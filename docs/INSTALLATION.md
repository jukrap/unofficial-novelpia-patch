# 설치와 업데이트

[문서 목차](README.md) · [빠른 사용 안내](USAGE.md) · [문제 해결](FAQ.md)

## 지원 환경

Chrome 120 이상에서 사용하는 데스크톱 확장프로그램입니다. 콘텐츠 기능은 `novelpia.com`과 `www.novelpia.com`의 회차 뷰어에서 작동합니다. 작품 목록이나 다른 사이트의 화면은 바꾸지 않습니다. 원사이트가 요구하는 로그인·구독·회차 접근 권한은 그대로 필요합니다.

다른 Chromium 브라우저에서는 동작이 다를 수 있습니다. 모바일 Chrome·Safari·Firefox 지원을 보장하지 않습니다.

## Chrome 웹 스토어

현재 첫 등록을 준비하고 있습니다. 심사 승인 후 이 문서와 저장소 첫 화면에 공식 설치 링크를 추가합니다. 등록 후보나 GitHub 릴리스가 있다는 사실만으로 스토어 공개가 완료된 것은 아닙니다.

스토어 설치본은 Chrome의 확장 업데이트 기능으로 갱신됩니다. 새 버전의 심사·공개와 각 브라우저에 전달되는 시점에는 차이가 있습니다.

## 개발자 모드로 설치

### 1. 확장 폴더 만들기

소스 빌드에는 Git, Node.js 26.10 이상, pnpm 12.9.1이 필요합니다. 확장을 사용하는 사람에게 Node.js가 필요한 것은 아니며, 직접 빌드하는 경우에만 설치합니다.

```sh
git clone https://github.com/jukrap/unofficial-novelpia-patch.git
cd unofficial-novelpia-patch
npm install --global pnpm@12.9.1
pnpm install --frozen-lockfile
pnpm run build
```

일반 확장 폴더는 `.output/chrome-mv3`입니다. `.output/chrome-mv3-e2e`는 합성 테스트 주소용이므로 노벨피아에서 사용할 설치본이 아닙니다.

[GitHub Releases](https://github.com/jukrap/unofficial-novelpia-patch/releases)에 검증된 Chrome ZIP이 공개되어 있다면, 직접 빌드하는 대신 ZIP을 빈 폴더에 풀어 사용할 수 있습니다. 미공개 초안이나 Actions 테스트 산출물을 설치하지 마세요.

### 2. Chrome에 등록

1. 주소창에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. `manifest.json`이 바로 들어 있는 폴더를 선택합니다. 소스 저장소 전체나 ZIP 파일 자체를 고르지 않습니다.
5. 노벨피아 회차를 새로고침하고 테마박스를 엽니다.

처음에는 **프리셋 → 기본**으로 시작한 뒤 필요한 항목을 조절해 보세요.

## 개발자 모드 설치본 업데이트

같은 설치 폴더를 유지하면 확장 ID와 로컬 데이터도 유지하기 쉽습니다. 먼저 설정 파일을 내보낸 뒤 새 소스를 빌드하거나 새 ZIP을 기존 설치 폴더에 반영합니다.

1. `chrome://extensions`에서 해당 확장의 **새로고침**을 누릅니다.
2. 이미 열려 있던 노벨피아 회차도 새로고침합니다.
3. 확장 팝업이나 정보 화면에서 버전을 확인합니다.

개발자 모드 설치본은 웹 스토어가 자동 업데이트하지 않습니다. 기존 확장을 삭제하고 다른 폴더에서 다시 등록하면 같은 데이터가 이어진다고 보장할 수 없습니다.

## 개발용 확장에서 스토어 확장으로 이전

확장 ID가 다르면 두 설치본의 저장소도 분리됩니다. 기존 확장을 제거하기 전에 아래 순서로 옮기세요.

1. 기존 확장의 **설정 파일 → 파일로 저장**으로 JSON을 내보냅니다.
2. 등록했던 이미지·글꼴의 원본 파일을 따로 보관합니다.
3. 기존 확장을 꺼서 두 확장이 같은 회차를 동시에 처리하지 않게 합니다.
4. 새 스토어 설치본에서 **설정 파일 → 가져오기**를 진행합니다.
5. 필요한 파일을 다시 등록하고, 현재 설정과 프리셋에서 해당 글꼴·이미지를 다시 선택합니다.
6. 새 설치본의 동작을 확인한 뒤 기존 설치본을 정리합니다.

| 항목                                   | 이전 방법                      |
| -------------------------------------- | ------------------------------ |
| 글꼴·간격·색상·읽기 방식과 페이지 옵션 | 설정 JSON                      |
| 사용자 프리셋                          | 설정 JSON                      |
| 외부 이미지 주소·내장 배경 선택        | 설정 JSON                      |
| 등록 이미지·글꼴의 실제 파일           | 원본 파일을 다시 등록하고 선택 |
| 자동 읽기 위치·수동 북마크·독서 통계   | 현재 이전 기능 없음            |
| 자동 추천 동의                         | 새 설치본에서 직접 선택        |

## 기본 뷰어로 돌아가기

테마박스·설정 페이지 정보 탭 또는 확장 팝업의 **확장 뷰어 사용**을 끕니다. 현재 회차에서 전환하면 위치를 저장한 뒤 새로고침하며, 다른 열린 회차에는 새로고침 안내를 표시합니다.

확장 자체를 제거하면 브라우저의 확장 로컬 데이터도 사라질 수 있습니다. 먼저 필요한 설정과 원본 파일을 보관하세요. 원사이트 계정과 구매 내역은 확장의 저장 데이터가 아닙니다.
