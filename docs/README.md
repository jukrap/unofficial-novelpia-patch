설정 파일에는 등록한 글꼴·이미지 파일과 독서 기록이 포함되지 않습니다. 다른 브라우저나 다른 확장 ID로 옮기려면 [설정과 파일 이전 안내](USAGE.md)를 확인하세요.

작업 일지·개인 환경·실제 작품을 사용한 검증 자료는 공개 문서의 일부가 아닙니다. 문서에 적힌 검사 방법과 실제 실행 결과, 배포 구성과 현재 활성화 상태도 구분합니다.
