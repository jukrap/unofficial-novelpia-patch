# 자주 묻는 질문과 문제 해결

[문서 목차](README.md) · [설치·이전](INSTALLATION.md) · [자세한 설정](USAGE.md)

## 어떤 프로그램인가요?

노벨피아의 회차 뷰어에서 글꼴·간격·색상·읽기 방식을 조절하는 비공식 확장입니다. 별도의 소설 서비스나 작품 다운로드 도구가 아닙니다. 원사이트의 로그인·결제·접근 권한을 그대로 사용합니다.

## 테마박스가 바뀌지 않아요

- 회차 뷰어에서 사용 중인지 확인합니다. 작품 소개·목록 페이지는 적용 대상이 아닙니다.
- 확장 팝업에서 **확장 뷰어 사용**이 켜져 있는지 확인합니다.
- 확장을 설치하거나 새로고침한 뒤에는 회차 페이지도 새로고침합니다.
- 개발자 모드라면 `.output/chrome-mv3`를 등록했는지 확인합니다. E2E 폴더는 실제 사이트용이 아닙니다.
- 예전 개발용 설치본과 스토어 설치본이 동시에 켜져 있다면 하나만 사용합니다.

`Extension context invalidated`는 확장이 다시 로드되어 기존 탭의 연결이 끝났을 때 나타날 수 있습니다. 회차를 새로고침해 새 연결로 열어 보세요. 반복된다면 확장·브라우저 버전과 재현 순서를 알려 주세요.

## 설정 페이지와 테마박스는 무엇이 다른가요?

같은 읽기 설정을 사용합니다. 테마박스는 읽으면서 조절하는 화면이고, 별도 설정 페이지는 사용자 글꼴 파일·설정 파일·통계를 관리하는 화면입니다. 현재 회차에 연결되는 정주행·본문 탐색은 테마박스에서 제공합니다.

## 스크롤과 페이지 중 어느 쪽이 저장되나요?

**레이아웃 → 읽기 방식**에서 선택한 값이 저장됩니다. 새 프리셋에도 읽기 방식과 페이지 구성이 들어갑니다. 방식을 변경하면 위치를 저장하고 열린 회차를 새로고침합니다.

구형 프리셋에 읽기 방식이 없으면 현재 방식을 유지합니다. 편집하거나 복제해 다시 저장하면 읽기 방식도 포함됩니다. 자동 두 쪽은 두 본문과 간격이 화면에 들어갈 때만 두 쪽으로 표시됩니다.

## 줄 간격·문단 간격·빈 줄 간격이 다른가요?

**줄 간격**은 한 문장이 여러 줄로 감길 때의 줄 높이입니다. **문단 간격**은 작가가 줄을 나눈 문단 뒤의 여백이고, **빈 줄 간격**은 원문에 있는 빈 줄의 높이입니다. 같은 값으로 맞출 필요는 없습니다.

## 글꼴이나 배경 이미지가 보이지 않아요

웹글꼴이나 URL 이미지는 제공 서버의 응답이 필요합니다. 선택 항목의 오류와 재시도 안내를 확인하거나, 시스템 글꼴·단색 배경으로 먼저 읽어 보세요. 등록한 파일은 인터넷 없이 사용할 수 있지만 다른 브라우저로 자동 이전되지는 않습니다.

설정 파일을 가져온 뒤 파일이 없다고 나오면 원본을 다시 등록하고 선택해야 합니다. 내장 배경 4종은 확장에 포함되어 있어 재등록이 필요하지 않습니다.

## 프리셋을 편집하면 읽는 화면도 바뀌나요?

편집 중인 초안은 현재 읽기 설정과 분리됩니다. **저장**은 프리셋만 보관하고, **저장하고 적용**은 읽기 화면에도 반영합니다. **현재 읽기 설정 가져오기**는 지금 뷰어에서 사용하는 값을 초안으로 복사합니다.

다른 화면에서 같은 프리셋을 수정하면 충돌을 알립니다. 저장에 실패한 초안을 닫기 전에 오류를 확인하세요.

## 읽던 위치 대신 처음으로 돌아왔어요

90% 이상 읽은 회차는 거의 다 읽은 것으로 처리해 자동 위치 대신 완료 표시만 남깁니다. 다시 열면 처음부터 시작합니다. 특정 장면에 돌아오려면 수동 북마크를 저장하세요. 수동 북마크는 이 완료 규칙과 별개입니다.

위치는 문단과 글자 기준으로 보관합니다. 작가가 원문을 수정했거나 브라우저 저장소가 지워진 경우 같은 위치를 정확히 찾지 못할 수 있습니다.

## 마지막 쪽에는 왜 넘김 효과가 없나요?

커버가 있는 쪽과 마지막 쪽에는 커버 버튼·후기·광고·다음화 이동 등의 서비스 요소가 섞일 수 있습니다. 본문 효과와 겹치지 않도록 이 쪽을 오갈 때는 즉시 전환합니다. 운영체제의 동작 줄이기를 켠 경우에는 다른 쪽의 효과도 생략합니다.

## 저장 실패·통계 오류가 나요

오류가 난 작업의 안내를 먼저 확인하세요. Chrome 동기화 저장 공간이 부족하다면 설정을 내보낸 뒤 불필요한 사용자 프리셋을 정리할 수 있습니다. 등록 이미지·글꼴과 독서 통계에는 별도 로컬 용량 제한이 있습니다.

통계 오류는 읽기 기능과 분리됩니다. **기타**에서 통계 기록을 끄거나 다시 시도할 수 있습니다. 설정 초기화는 프리셋·등록 파일·위치·북마크·통계를 지우지 않습니다.

## 기록을 외부로 보내나요?

개발자 수집 서버로 독서 기록을 보내지 않습니다. 다만 읽기 설정·프리셋의 Chrome 동기화와 웹글꼴·URL 이미지의 외부 요청은 발생할 수 있습니다. [저장 위치와 삭제 방법](PRIVACY.md)을 확인하세요.

## 해결되지 않으면

[문제 신고 양식](https://github.com/jukrap/unofficial-novelpia-patch/issues/new/choose)에 확장 버전, 브라우저 버전, 스크롤/페이지 여부와 재현 순서를 적어 주세요. 화면에는 작품 원문과 계정 정보를 가리고, 쿠키·인증 값·전체 브라우저 프로필은 첨부하지 마세요.
