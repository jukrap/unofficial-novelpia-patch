# 스토어 이미지

버전 0.1.1의 일반 배포 빌드를 격리된 MV3 Chromium에서 실행해 촬영했습니다. 각 화면에는 해당 기능의 용도를 설명하는 제목과 짧은 소개를 붙였습니다.

| 파일                                     | 소개하는 기능                           | 크기     |
| ---------------------------------------- | --------------------------------------- | -------- |
| [01-reading.png](01-reading.png)         | 두 쪽 읽기와 본문 너비·여백             | 1280×800 |
| [02-typography.png](02-typography.png)   | 실제 테마박스와 글꼴·간격 조절          | 1280×800 |
| [03-presets.png](03-presets.png)         | 이미지 배경을 포함한 기본 프리셋과 편집 | 1280×800 |
| [04-backgrounds.png](04-backgrounds.png) | 어두운 본문과 동봉 배경 이미지          | 1280×800 |
| [05-user-fonts.png](05-user-fonts.png)   | 글꼴 파일 등록과 지원 두께              | 1280×800 |
| [promo-440x280.png](promo-440x280.png)   | 작은 홍보 이미지                        | 440×280  |

스토어 스크린샷에는 위 순서로 다섯 장을 사용합니다. 홍보 이미지는 별도 작은 프로모션 타일 항목에 넣습니다. 아이콘은 [icon128.png](../../public/icons/icon128.png)를 사용합니다.

## 화면의 출처

본문은 촬영을 위해 직접 작성한 짧은 허구 이야기입니다. 실제 작품 원문·계정·광고를 수집하지 않습니다. 합성 호스트 페이지에 **실제 배포 확장**을 적용했으므로 노벨피아 사이트 전체의 모양을 재현한 이미지는 아닙니다.

테마박스, 독서 영역, 프리셋, 글꼴 관리 화면은 확장이 렌더링한 그대로 촬영합니다. UI 안의 텍스트·배치·색상을 사후 교체하거나 기능을 합성하지 않습니다. 화면 바깥의 제목·설명·프레임은 홍보용 구성입니다.

## 다시 촬영하기

의존성과 Playwright Chromium을 설치한 뒤 실행합니다.

```sh
pnpm run build
node scripts/store-assets.mjs
```

최종 이미지는 이 폴더에, 프레임을 붙이기 전 캡처와 버전 정보는 무시되는 `test-results/store-captures/`에 저장합니다. 임시 브라우저 프로필은 종료 시 정리합니다.

촬영 스크립트는 실제 노벨피아 문서를 요청하지 않고 합성 HTML로 응답합니다. 프리젠테이션 독서 글꼴은 동일한 동봉 파일로 응답하며 다른 웹글꼴은 실제 로더를 사용합니다. 글꼴·이미지·본문 준비가 끝난 것을 확인한 뒤 촬영합니다. 자원이 실패하거나 화면이 잘리면 결과를 게시하지 말고 다시 검수하세요.

이미지 크기·형식과 공개 내용은 [Chrome 스토어 등록 기준](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)에 맞춰 확인합니다. 이 자료는 심사 승인이나 공식 제휴를 의미하지 않습니다.
