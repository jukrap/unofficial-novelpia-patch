# Chrome 웹 스토어 등록 자료

첫 등록용 초안입니다. 심사 제출이나 공개 완료를 의미하지 않습니다. 저장소 공개 검토와 개인정보 안내 URL 접근 확인을 마친 뒤 사용합니다.

## 기본 정보

- 이름: Unofficial Novelpia Patch
- 버전: 0.1.1
- 기본 언어: 한국어
- 짧은 설명: 글꼴, 여백, 테마, 페이지 읽기를 조절하는 노벨피아 비공식 뷰어 확장
- 분류: 도구 / 생산성 범주에서 읽기 환경에 맞는 항목
- 홈페이지: https://github.com/jukrap/unofficial-novelpia-patch
- 지원: https://github.com/jukrap/unofficial-novelpia-patch/issues
- 개인정보 안내: https://github.com/jukrap/unofficial-novelpia-patch/blob/main/docs/PRIVACY.md

현재 저장소가 비공개라면 위 URL은 일반 사용자에게 열리지 않습니다. 공개 전환과 비로그인 접근 확인 전에는 스토어에 제출하지 않습니다. 개발자 연락처는 대시보드에 등록된 실제 연락처를 사용하며 소스에 기록하지 않습니다.

## 상세 설명

읽는 방식부터, 내 취향대로.

Unofficial Novelpia Patch는 노벨피아의 읽기 화면을 조절하는 비공식 커뮤니티 확장프로그램입니다. 익숙한 스크롤로 읽거나 책처럼 한 쪽·두 쪽으로 펼치고, 내 화면과 취향에 맞는 글꼴·여백·배경을 찾아보세요.

■ 편한 화면으로 읽기
스크롤·한 쪽·두 쪽 읽기를 선택하고 본문 너비·높이·여백을 조절합니다. 읽기 방식과 관련 설정도 다음 회차에서 유지됩니다.

■ 글꼴과 간격을 세밀하게
글자 크기·두께, 줄·문단·빈 줄 간격을 각각 조절합니다. 작가가 강조한 문장은 그림자·배경·테두리로 더 구별되게 표시할 수 있습니다. 가지고 있는 글꼴 파일도 이름과 지원 두께를 확인해 등록합니다.

■ 분위기부터 고르는 프리셋
기본 프리셋 10개에서 시작해 나만의 설정으로 편집·복제하세요. 단색과 동봉 배경 이미지 4종을 제공하며 이미지 주소나 내 파일도 사용할 수 있습니다. 프리셋은 본문에 적용하기 전에 별도 초안에서 미리 봅니다.

■ 이어 읽고, 기록 확인하기
회차별 읽던 위치와 수동 북마크를 따로 보관합니다. 90% 이상 읽은 회차는 다시 방문할 때 처음부터 시작합니다. 독서 시간·열어 본 회차·독서한 날은 이 브라우저에서 확인하고 기록을 끄거나 삭제할 수 있습니다.

■ 설정을 파일로 보관하기
읽기 설정과 내 프리셋을 JSON으로 내보내고 가져옵니다. 등록한 글꼴·이미지 파일과 읽기 기록은 JSON에 포함되지 않습니다.

회차의 기존 테마박스 버튼에서 읽기 설정을 열 수 있습니다. 확장 아이콘의 ‘설정 열기’에서는 등록 글꼴·설정 파일·통계를 관리합니다. 필요하면 기본 뷰어로 다시 전환할 수 있습니다.

읽기 설정과 프리셋은 Chrome 동기화 설정에 따라 동기화될 수 있습니다. 등록 파일과 읽기 기록은 이 브라우저에 보관하며 개발자 서버로 보내지 않습니다. 웹글꼴과 이미지 주소를 사용하면 해당 제공처로 일반적인 자원 요청이 발생합니다.

이 확장은 노벨피아와 공식적인 관계가 없습니다. 광고·결제·회차 접근 권한을 우회하지 않습니다. 서비스 화면 변경으로 일부 기능이 달라질 수 있습니다. 커버가 있는 쪽과 마지막 쪽은 효과 없이 넘기며, 등록 파일·독서 기록은 설정 JSON에 포함되지 않습니다.

## 단일 목적과 권한 설명

단일 목적: 노벨피아 웹소설 뷰어의 글꼴·간격·화면 배치와 읽기 보조 기능을 사용자가 조절하도록 합니다.

`storage`: 읽기 설정과 프리셋을 동기화 저장하고, 읽기 위치·북마크·독서 통계·초기 화면 캐시를 로컬에 보관합니다.

사이트 접근: `https://novelpia.com/viewer/*`와 `https://www.novelpia.com/viewer/*`에서 본문을 읽어 배치하고 테마박스·페이지 탐색을 적용합니다. 광고·유료 접근·원사이트 요청은 우회하지 않습니다.

원격 실행 코드: 사용하지 않습니다. JavaScript와 지연 로딩 모듈은 확장 패키지에 포함합니다. 외부에서 읽는 글꼴 CSS·파일과 배경 이미지는 실행 코드가 아닌 표시 자원입니다.

## 개인정보 항목 작성 기준

[개인정보 안내](../docs/PRIVACY.md)의 실제 처리 범위를 기준으로 대시보드의 항목을 작성합니다. 서버 전송이 없다는 이유로 데이터 처리가 전혀 없다고 표시하지 않습니다.

- 웹사이트 콘텐츠: 열린 회차 본문을 메모리에서 읽어 배치하며 작품 원문을 수집 서버에 보내지 않습니다.
- 웹 기록·사용자 활동: 회차 ID·읽기 위치·독서 시간 등을 기능에 필요한 범위에서 로컬 처리합니다. 다른 사이트의 방문 기록은 읽지 않습니다.
- 사용자가 제공한 파일·설정: 등록 파일은 확장 IndexedDB, 설정·프리셋과 참조 ID는 Chrome 동기화 저장소에 보관합니다.
- 식별·인증·결제 정보: 확장 기능에서 수집하지 않습니다.

데이터 판매, 목적과 무관한 제3자 이전, 신용·대출 판단 사용은 하지 않습니다. 신고 항목과 공개 개인정보 안내가 일치하는지 최종 대조합니다.

## 심사 확인 절차

1. 일반 공개된 무료 회차를 정상 접근 권한으로 엽니다. 유료 구독이나 확장 계정은 필요하지 않습니다. 원사이트가 로그인 등을 요구하면 정상 절차를 따릅니다.
2. 기존 테마박스에서 글자 크기·간격·색상을 변경하고 본문에 적용되는지 확인합니다.
3. 페이지 읽기와 스크롤 읽기를 전환하고 회차 목록·광고·원사이트 메뉴가 유지되는지 확인합니다.
4. 확장 팝업의 설정 열기에서 프리셋을 적용하고 파일 내보내기를 확인합니다.
5. 정보의 확장 사용 스위치를 끄고 새로고침하여 기본 뷰어로 돌아가는지 확인합니다.

첨부 화면은 [촬영 안내](assets/README.md)에 설명한 합성 본문에서 실제 확장을 실행한 이미지입니다. 앱 기능을 보여주며 작품 원문이나 계정 정보를 포함하지 않습니다.

새 항목 생성과 제출 전 확인은 [첫 등록 순서](FIRST_SUBMISSION.md), 이후 자동 업데이트는 [배포 운영](../docs/RELEASE.md)을 따릅니다.
